# Body Factory PWA v1

## Запуск на Android без ПК

PWA должен быть размещён на HTTPS-сайте. После размещения:

1. Откройте адрес в Chrome на Android.
2. Выберите меню Chrome → «Добавить на главный экран» / «Установить приложение».
3. На рабочем столе появится Body Factory.
4. Приложение работает в отдельном окне.

## Важно

Service Worker требует HTTPS (исключение — localhost). Поэтому просто открыть index.html из файлового менеджера недостаточно для полноценной установки PWA.

## Возможности

- локальные сохранения через localStorage;
- база продуктов;
- добавление и удаление собственных продуктов;
- дневник питания;
- дневник веса, шагов и тренировок;
- график веса;
- уровни и прогресс;
- экспорт/импорт резервной копии JSON;
- офлайн-кэш после первого открытия при корректном HTTPS-размещении.
